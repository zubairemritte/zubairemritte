# Project briefs

These briefs describe the business questions, intended users, data requirements and evaluation plans for five independent data products. The projects are planned builds. Demonstrations and measured results will be linked as each product is delivered.

| Order | Product | Main question | Current state |
| --- | --- | --- | --- |
| 1 | [CareerGraph Europe](projects/careergraph-europe.md) | Which skills are employers asking for, and how does a candidate's profile compare? | Scoped; repository initialized |
| 2 | [LuxRisk Intelligence](projects/luxrisk-intelligence.md) | How can an analyst compare traceable economic and financial indicators? | Planned |
| 3 | [PricePulse AI](projects/pricepulse-ai.md) | How can we compare prices, forecast demand and evaluate a pricing decision? | Planned |
| 4 | [AMLGraph](projects/amlgraph.md) | How can transaction alerts be prioritised and explained using synthetic data? | Planned |
| 5 | [Data Platform Lab](projects/data-platform-lab.md) | How can a data workload be deployed, monitored and recovered reliably? | Planned |

Each brief defines an initial release, proposed methods and the evidence needed to evaluate the result. Implementation and technical documentation will live in the relevant project's repository.
